1. PURPOSE OF C17
=================

C17 is the independent lambda-zero fixed-budget control used to separate two
questions:

1. A17 - C17: at the same 17-epoch execution budget, what changes when the
   accepted adversarial arm A17 is compared with the lambda=0 C17 control?

2. C17 - C_long: for lambda=0, what changes when the 17-epoch C17 control is
   compared with the accepted long-budget control C_long?

This design keeps the model seed matched in every comparison. It is a post-hoc
three-seed sensitivity analysis. It does not establish causality, legal
discrimination, creditworthiness, or default risk.

3. EVALUATION LOGIC
===================

3.1 Threshold selection
-----------------------

Each seed uses its own Validation predictions. The chosen global threshold is
the candidate that maximizes Validation balanced accuracy over 999 candidates:

  0.001, 0.002, ..., 0.999

Tie-breaking is locked as:

  1. threshold closest to 0.5;
  2. lower threshold if a tie remains.

The threshold is locked on Validation before Test is evaluated. Test does not
participate in threshold selection.

3.2 Metrics
-----------

BA (balanced accuracy):

  BA = (TPR + TNR) / 2

Higher BA is better predictive performance.

EOD3 and EOD6 use fixed race-group rosters. For a roster, equalized-odds
disparity is:

  EOD = max(range of approved-positive TPR,
            range of approved-positive FPR)

Lower EOD means less disparity within the specified roster.

EOD3 roster:

  White
  Black or African American
  Asian

EOD6 roster:

  White
  Black or African American
  Asian
  American Indian or Alaska Native
  2 or more minority races
  Joint

All stored C17 EOD3 and EOD6 Test quantities are valid; no required roster group
is listed as invalid.

3.3 Direction of the comparison deltas
--------------------------------------

The stored delta is always comparator minus control:

  A17-C17     = metric(A17) - metric(C17)
  C17-C_long  = metric(C17) - metric(C_long)

For BA:

  positive delta = the first named arm has higher BA;
  negative delta = the first named arm has lower BA.

For EOD:

  negative delta = the first named arm has lower disparity;
  positive delta = the first named arm has higher disparity.

3.4 Confidence intervals
------------------------

Every comparison uses the same ordered Test rows within a seed and the locked
Test bootstrap indices:

  SHA-256: 2ee377b6fbae8a3a6453a7d8f2f4a0a3f1ce61374f1258ef882589b84230fee1

For each seed and comparison:

  Replicates:                   1,000 paired replicates
  Confidence interval:         two-sided 95% percentile interval
  Quantiles:                   0.025 and 0.975
  Quantile interpolation:      linear
  Validity requirement:        1,000/1,000 valid values per quantity
  Replacement/top-up:          none
  Rounding before quantiles:    none

All 18 delta intervals below have 1,000/1,000 valid replicates, zero invalid
replicates, and are evaluable.

The package does not store a standalone bootstrap CI for the absolute C17 BA,
EOD3, or EOD6 values. The available CIs are paired CIs for comparison deltas.
No standalone C17 CI is invented in this report.

8. WHAT THE STORED RESULTS SUPPORT
==================================

1. The 17-epoch C17 control has very similar BA across the three seeds
   (approximately 0.7805-0.7815), with EOD3 approximately 0.1008-0.1064.

2. A17 versus C17 does not show a seed-specific BA difference whose 95% CI
   excludes zero. The only A17-C17 disparity interval excluding zero is EOD3
   for seed 43, favoring lower EOD3 for A17.

3. C17 has lower BA than C_long in every seed, and all three paired BA CIs are
   entirely below zero. This is the clearest consistent comparison result in
   the stored C17 package.

4. C17-C_long EOD3 and EOD6 intervals all cross zero. The stored evidence does
   not support a consistent seed-specific non-zero fairness difference between
   the short and long lambda-zero controls.

5. The across-seed mean and sample SD are descriptive only. Bootstrap values
   were not pooled across seeds, and the package makes no across-seed
   significance claim.


9. LIMITATIONS
==============

  - Only three seeds are included.
  - This is a post-hoc fixed-budget sensitivity analysis.
  - Same-seed pairing improves comparison precision but does not establish a
    causal effect.
  - Bootstrap inference is conditional on the fitted models and the locked
    Validation thresholds.
  - A CI including zero is not proof that the arms are equivalent.
  - The package contains paired delta CIs, not standalone C17 metric CIs.
  - EOD3 and EOD6 refer only to their locked fixed rosters and must not be
    generalized to every possible protected-group definition.
  - The diagnostic CE replay BLOCK is not an acceptance failure, but historical
    weight equivalence was not proven.
  - The stored execution package reported PASS at completion time; current
    canonical repository closure/revalidation is a separate unresolved issue.
